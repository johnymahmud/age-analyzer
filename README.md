# লাইফ-টাইমলাইন ও হিস্টোরিক্যাল এজ অ্যানালাইজার (Life Timeline & Age Analyzer)

একটি অত্যাধুনিক, ইন্টারেক্টিভ ও আধুনিক এজ অ্যানালাইজার এবং অ্যাস্ট্রোলজিক্যাল/পালমিস্ট্রি ওয়েব অ্যাপ্লিকেশন।

## 🚀 লোকাল হোস্টে রান করার নিয়ম

প্রজেক্ট ডিরেক্টরিতে টার্মিনাল খুলে নিচের যেকোনো একটি কমান্ড দিয়ে রান করতে পারেন:

### অপশন ১: Node.js / NPM দিয়ে (রিকমেন্ডেড)
```bash
npm start
```
বা
```bash
node server.mjs
```

### অপশন ২: Live Server / Any Static Server
```bash
npx serve .
```

সার্ভার চালু হলে ব্রাউজারে নিচের ঠিকানায় প্রবেশ করুন:
👉 **[http://localhost:8088/](http://localhost:8088/)**
